How it works

Three steps to your first chapter.

  1. Install the Mac app

    It sits in your menu bar and runs the local speech service. You only open it to pick a model or voice.

  2. Download a model

    In Settings → Models, start with Kokoro 82M: about 0.2 GB and quick to load. Add bigger models later.

  3. Read in Chrome

    Click the VacReader button on a page, select a passage, or open an EPUB with Read a book. Press Alt+Shift+R to start or pause.

Download · Alpha

Get VacReader for your Mac and Chrome.

This is an alpha. It works every day for reading, and you may still find rough edges. The app updates itself, and the extension with it.

Mac app

Apple Silicon (M1 or newer) · macOS 15+ · VacReader zip

Download for Mac
  1. Unzip and drag VacReader.app into Applications.
  2. The alpha is not notarized by Apple yet. Run xattr -dr com.apple.quarantine /Applications/VacReader.app in Terminal, or open it once and choose System Settings → Privacy & Security → Open Anyway.
  3. Open VacReader from the menu bar and download a model in Settings → Models.

Chrome extension

Chrome 116+ or another Chromium browser · Extension zip

  1. Install the Mac app first. It puts the extension in ~/Library/Application Support/QwenReader Extension and keeps that folder up to date.
  2. Open chrome://extensions, turn on Developer mode and click Load unpacked.
  3. Choose that folder. Library is hidden in the file picker: press ⌘⇧G and paste the path above. Then pin VacReader to the toolbar and leave Developer mode on so updates keep working.

No Mac app here? Download the extension zip. A folder loaded from the zip does not update; load a new zip after each release.

Questions

Good to know

Does anything I read get uploaded?

No. The extension sends the text only to the VacReader service on your own Mac (127.0.0.1). Speech is generated there. The app reaches the internet only to download models from Hugging Face and to check GitHub for updates once a day.

What can it read?

Web pages and selected passages in Chrome, DRM-free EPUB books, PDF papers and Markdown. On Wikipedia and X it adds a play button to each section or post.

Why is it an alpha?

The app is new and still changing quickly. It is not notarized by Apple or listed in the Chrome Web Store yet, so installation takes a couple of extra steps.

Does it work on Intel Macs or Windows?

Not yet. The speech engine needs an Apple Silicon Mac (M1 or newer) with macOS 15 or newer.

How much disk space do models need?

From about 0.2 GB for Kokoro 82M up to a few GB for the larger models. You can delete a model at any time in Settings → Models.
